# Small ML Projects

These projects bridge the gap between guided tutorials and the larger D2L
projects. Each one uses a public dataset and asks for a complete, defensible
machine-learning workflow.

The briefs deliberately do not provide finished notebooks. They define the
problem, constraints, checkpoints, and completion standard while leaving the
implementation and most modeling decisions to the student.

## Sequence

1. [Bank Marketing Classification](project_01_bank_marketing/PROJECT_BRIEF.md)
2. [Bike Sharing Regression](project_02_bike_sharing/PROJECT_BRIEF.md)
3. [Adult Census Messy-Data Classification](project_03_adult_census/PROJECT_BRIEF.md)

## Working agreement

- Use Google Colab unless a project brief says otherwise.
- Type and run the work yourself.
- Do not begin from a public solution notebook.
- Use documentation for individual APIs freely.
- Ask for help through the hint ladder in the project brief.
- Finish the analysis and reflection, not merely model training.

The goal is not a leaderboard score. The goal is to turn an unfamiliar public
dataset into a reproducible training and evaluation workflow that another
person can inspect.
